# From supplied notes to testable behavior

The supplied `01-Книга.txt` is a thematic summary of Chip Huyen's book. The original
book/PDF was not read for this implementation. Its product conclusions are already
identified in the note as the note author's interpretation. `02-Системы.txt` is an
explicitly separate interpretation of system improvement; `03-Заметки-и-проект.txt`
contains corrections and a proposed learning project. Neither is attributed to the
book author. The engineering decisions below are this project's implementation of
those ideas, not quotations or claims that the book prescribes this architecture.

Full notes are intentionally absent from this repository. Source section names are
included so the owner can audit the mapping against the supplied files.
