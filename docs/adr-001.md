# ADR 001 — Small local infrastructure

Accepted. Use SQLite for durable records, transactional local effects and FTS5 BM25. Store normalized embedding vectors in the same database and calculate exact cosine within prefiltered eligible records. For the small research corpus this removes a second embedded database owner while retaining true dense retrieval. It is not a scale benchmark. RRF combines rank positions, not raw scores.

Use a bounded explicit workflow for fixture/local RELAY. Persist state, approval hashes, outputs and idempotency ledger in SQLite transactions. This is not autonomous model planning and is not an exactly-once external effect guarantee. The live provider may propose typed tools but code owns validation and transitions. LangGraph and Qdrant are intentionally not dependencies; their APIs are not used.

Use buildless HTML/CSS/JavaScript modules served by FastAPI: six dedicated views, no frontend compilation required. This retains reproducibility on the local environment. Pydantic supplies typed contracts and generated OpenAPI. Native frontend functions are browser tested. This is a local research app, not an authenticated multi-tenant service.
