# Limits of the delivered evidence

- **The withheld follow-up challenge still fails 5 of 12 cases under all four methods**: `IQ2-05` opacity, `IQ2-06` maximum logo width, `IQ2-07` font-file redistribution permission, `IQ2-08` campaign timezone and `IQ2-09` warranty compensation. Related source passages are real, but they do not answer the requested missing attributes. The responses incorrectly say `supported`. Both baseline and final remain 7/12. See [independent-quality.json](reports/public/independent-quality.json).
- The original visible CANON suite now passes 32/32. The first independently authored 26-case set improved from 20/23 to 23/23 scored cases; three ambiguous cases remain unscored. Those questions were disclosed before fixes and became regressions, not an untouched final holdout. Intermediate regressions and baseline outputs remain in the quality reports. No general source-grounded answering reliability is established.
- Extraction uses Snowball 3.1.1 English/Russian stemming, scoped heading/tag anchors, distinctive body terms, a small declared glossary and format/action guards. These are bounded heuristics, not a general intent or entailment model. Bilingual passages and extra irrelevant source sections can appear. Source authenticity does not establish query sufficiency. There is no visual generation, OCR, visual evaluator or pixel embedding.
- Six security findings and three implementation-review findings were repaired and directly rechecked within their stated scopes. Initial failures and a partially fixed export stage are retained. Same-session delegated review is not an external human audit, certification, or complete security analysis. [Security evidence](reports/public/independent-security.json) and [implementation evidence](reports/public/independent-review.json) do not replace final delivery checks.
- Public data and gold are synthetic and machine-authored. The independent challenge author used source guides rather than existing gold, but this is still a small authored sample with no expert validation. The second challenge was withheld from the implementer until its final freeze; it was authored with knowledge of earlier behavior, not independently of all prior work. No STC or population-level conclusion follows.
- Final normal SENTINEL comparison is `PASS` on the original suite. The gate can still return `REGRESSION` for existing critical failures even without newly regressed cases; that policy is retained. Passing this gate does not establish significant improvement, question sufficiency beyond its cases, or fitness for release.
- Semantic cache uses a small validation set and conservative object/number/code/negation/context guards. It may miss valid reuse and cannot establish semantic equivalence in arbitrary language. Actual local answer calls and durations are measured; live monetary savings and human rework are not measured.
- Real CPU embeddings were prepared and exercised; fixture mode deliberately cannot perform dense or semantic reuse. Vectors represent text only. Exact scoped search is for a tiny corpus, not a scalability claim.
- RELAY fixture/local execution is an explicit bounded workflow. The optional live adapter lets a model propose tools, but its designer handoff tool uses the same deterministic checked workflow. No real LLM run, live agent quality, free-form judge calibration or no-context live comparison was measured. Live CLI currently supplies bounded smoke runs, not a full cross-provider benchmark.
- RELAY's default deadline includes waiting for a human. An expired workflow fails explicitly. SQLite can atomically commit local artifact content and an idempotency ledger; file export is an atomic materialization, not an external exactly-once guarantee.
- LENS proves only faults actually reproduced by its isolated demos. Other classifications remain hypotheses. Recorded replay does not rerun external effects, and incident drafts require separate confirmation before becoming gold.
- STC is missing; no private brand corpus was imported. The compatible importer preserves private snapshots, but adding them to a separate private searchable application requires deliberate configuration/review. Public UI serves only the synthetic corpus.
- This is a local single-process research application, without production authentication, service isolation or multi-user authorization. Demo scope tests are not SaaS security certification. Private-data scans are heuristics, not comprehensive semantic or historical secret audits.
- Model weights/runtime/session files are excluded from the publishable review copy. Initial dependency/model installation needs network. Remote CI outcomes are available in GitHub Actions; checked-in local and independent reports describe their own earlier validation snapshots. There are no deployment claims.
- Distribution is checkout-only. Resource paths assume the repository layout; the misleading wheel/console-script metadata was removed. No successful wheel build, pip installation or relocated-package support is claimed.
